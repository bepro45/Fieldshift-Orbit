FieldShift Orbit — static deployment package

CONTENTS
- index.html: complete, self-contained web demo. CSS, JavaScript, crop-rotation engine,
  and the precomputed data pack are embedded in this file.

DEPLOY WITH NETLIFY DROP
1. Extract this ZIP on your computer.
2. Open https://app.netlify.com/drop and sign in or create a free account.
3. Drag the extracted folder (the folder containing index.html) onto the Netlify Drop page.
4. Wait for deployment. Netlify will provide a public URL ending in netlify.app.
5. Open that URL in an incognito/private window to confirm it works without login.
6. Copy the public URL into the Project URL / Demo URL field of your submission.

IMPORTANT PROJECT NOTES
- This is a static, browser-run demo. It does not require a backend server or database.
- The data pack is embedded in index.html; the displayed data are a precomputed snapshot,
  not live API calls. Data coverage in the pack ends 2025-12-31.
- The current pilot location is Soroti, Teso, Uganda (not Karnataka). Do not describe this
  build as a Karnataka deployment unless the location, datasets, crop catalogue, and
  agronomic assumptions are replaced and validated for Karnataka.
- Crop recommendations are decision-support scores under assumptions, not yield or profit
  forecasts. The app itself advises expert review.
